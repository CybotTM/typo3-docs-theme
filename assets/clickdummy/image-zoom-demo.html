RFC: Image Zoom for TYPO3 Docs Theme

This demo showcases proposed image zoom implementations for the TYPO3 documentation theme. Each approach can be enabled via guides.xml and controlled per-image with the :zoom: directive option.

Proposed RST Syntax

.. figure:: /Images/screenshot.png
   :alt: Backend screenshot
   :width: 150px
   :zoom: lightbox|gallery|inline|lens

   Caption text here

guides.xml Configuration

<extension class="..."
           image-zoom-enabled="true"
           image-zoom-library="dialog"  <!-- css|dialog|gallery|inline|lens -->
           image-zoom-max-scale="4"
/>

Comparison Summary

Option :zoom: value Size Best For

Inline Zoom inline ~1KB Stay-in-context, quick inspection
